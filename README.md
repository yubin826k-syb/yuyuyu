# 취준 기록실

아이패드, 노트북 등 여러 기기에서 같은 데이터를 보는 나만의 취업 준비 기록 웹앱입니다.
지원 기록 / 스크랩 / 채용공고를 한 곳에서 관리하고, "동기화 키"만 입력하면 어느 기기에서든 같은 데이터가 열려요.

## 포함된 파일
- `index.html` — 앱 전체
- `firebase-config.js` — Firebase 연결 정보 (직접 채워야 해요)
- `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` — 홈 화면 설치(PWA)용 파일

---

## 1) Firebase 설정하기 (최초 1회, 약 10분)

1. https://console.firebase.google.com 접속 → 구글 계정으로 로그인 → **"프로젝트 추가"**
2. 프로젝트 이름을 아무거나 입력 (예: `job-tracker`) → 애널리틱스는 꺼도 무방 → 프로젝트 생성
3. 왼쪽 메뉴에서 **Firestore Database** → "데이터베이스 만들기" → 위치는 아무 곳(예: asia-northeast3 서울)이나 선택 → **테스트 모드**로 시작
4. Firestore 생성 후, 상단 **"규칙(Rules)"** 탭으로 이동해서 아래 내용으로 바꾸고 "게시":
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /syncData/{docId} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```
   (로그인된 사용자만 읽고 쓸 수 있게 하는 규칙이에요. 앱은 익명 로그인을 자동으로 사용해요.)
5. 왼쪽 메뉴에서 **Authentication** → "시작하기" → **로그인 방법** 탭 → **"익명"** 제공업체를 사용 설정
6. 프로젝트 개요(⚙️ 톱니바퀴 옆 홈 아이콘) → **"웹 앱 추가"** (`</>` 아이콘) → 앱 닉네임 아무거나 입력 → 등록
7. 화면에 나오는 `firebaseConfig` 객체 값을 복사해서, 이 폴더의 `firebase-config.js` 파일을 열고 `YOUR_...` 부분을 실제 값으로 바꿔주세요.

## 2) GitHub Pages로 배포하기

1. GitHub에서 새 저장소 생성 (예: `job-tracker`)
2. 이 폴더의 파일 전체(`index.html`, `firebase-config.js`, `manifest.json`, `sw.js`, 아이콘 2개)를 업로드
3. 저장소 **Settings → Pages** → Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 설정 후 저장
4. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속 가능

**저장소는 Public이어야 무료로 Pages를 쓸 수 있어요.** 즉 URL을 아는 사람은 누구나 페이지를 열 수 있어요 (앱 안의 "동기화 키" 화면이 1차 장벽이지만 완전한 보안은 아니에요). 정말 민감한 정보는 넣지 않는 걸 추천해요.

## 3) 휴대폰/아이패드에 앱처럼 설치하기 (PWA)

배포된 주소로 접속한 뒤:
- **아이패드/아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가"
- **안드로이드(Chrome)**: 오른쪽 위 메뉴(⋮) → "홈 화면에 추가"

## 4) 사용 방법 — 동기화 키

앱을 처음 열면 "동기화 키"를 입력하는 화면이 나와요. 이 키는 비밀번호이자 "내 데이터 저장 공간을 찾는 열쇠" 역할을 해요.

- **아이패드**에서 키 `abcd1234`로 처음 입장 → 새 저장 공간이 만들어짐
- **노트북**에서 똑같이 `abcd1234`로 입장 → 아이패드에서 만든 데이터가 그대로 보임
- 키를 잊어버리면 그 데이터에는 다시 접근할 수 없으니, 잘 기억해두거나 메모해두세요.
- 오타로 다른 키를 입력하면 완전히 새로운 빈 공간이 열려요 (기존 데이터가 사라진 게 아니라, 다른 "방"에 들어간 것과 같아요 — 원래 키로 다시 입장하면 그대로 있어요).

## 5) 예전 버전에서 데이터 옮기기

Claude에서 쓰던 이전 페이지(또는 localStorage 버전)를 열어서 "데이터 내보내기" 버튼을 누르면 JSON 파일이 다운로드돼요. 이 앱 상단의 "데이터 가져오기"에서 그 파일을 선택하면 지금 로그인한 동기화 키의 저장 공간으로 데이터가 들어가요.
